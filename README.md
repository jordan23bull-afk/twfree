# Скрининг акций MOEX (TQBR)

Отбор акций за последнюю торговую сессию и график в одном одиночном файле.

## Файлы

| Файл | Что это |
|---|---|
| `rosn.html` | График и вочлист. Один файл: Lightweight Charts вшит внутрь. Данные берёт **только** из `data.json`, своего отбора в браузере нет. |
| `screener.mjs` | Отбор: запросы к MOEX ISS, фильтры, сборка истории, запись `data.json`. Запуск `node screener.mjs`. |
| `data.json` | Результат: вочлист с флагами + дневные OHLC по отобранным тикерам. |

## Как обновить данные

```bash
node screener.mjs
git add data.json
git commit -m "Обновил данные за <дата>"
git push
```

Затем страница подхватит файл автоматически. Параметры можно задать флагами:

```bash
node screener.mjs --value 5000000 --atr 100 --days 60
```

## Правила отбора

1. Оборот за день `VALUE` от 10 000 000 ₽ и объём `VOLUME` больше нуля.
2. ATR за день не меньше 150 пунктов: `(HIGH − LOW) / MINSTEP`, где `MINSTEP` — шаг цены конкретного тикера (у разных бумаг он разный, поэтому берётся отдельно для каждой).
3. Флаг: зелёный при `CLOSE > OPEN`, красный при обратном. При равных значениях — красный.

Сортировка — по убыванию ATR.

## Таймфреймы

`1 д` рисуется из `data.json` и работает всегда. Остальные (`1 мин`, `5 мин`, `1 ч`, `1 нед`) страница запрашивает у биржи напрямую, поэтому им нужен интернет.

## Обновление по расписанию

Пока файлы обновляются вручную. Автоматизацию можно добавить GitHub Actions с запуском по cron после закрытия торгов, чтобы скрипт сам коммитил свежий `data.json`.
